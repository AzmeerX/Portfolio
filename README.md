# Azmeer Farhan Portfolio

A static React portfolio for backend and distributed-systems project case studies. It uses JavaScript, Vite, React Router, and CSS — there is no backend, database, or TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL Vite prints in the terminal.

## Production build

```bash
npm run build
npm run preview
```

The deployable static files are created in `dist/`.

## Edit content

- Update project descriptions, metrics, skills, and links in `src/data/projects.js`.
- Update the page layouts in `src/pages/`.
- Update colors and shared style tokens in `src/index.css`.

## Deploy for free

Push this repository to GitHub, then import it into Vercel or Netlify. Both services detect Vite automatically. Use `npm run build` as the build command and `dist` as the publish directory if prompted.
